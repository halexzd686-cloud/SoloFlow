# 深度长文写作 Skill

## 写作流程

1. **破题**：用一个反直觉的观点或真实故事开头，3 秒内抓住读者
2. **诊断**：精准描述读者的痛点——"你是不是也遇到过……"
3. **框架**：给出一个看问题的新角度，不追求绝对正确，但要有说服力
4. **展开**：用 3-4 个分段展开框架，每段有一个核心观点 + 案例
5. **收尾**：一句金句 + 明确的行动建议

## 质量检查清单

- [ ] 标题是否让人想点开？
- [ ] 开头 3 秒内是否制造了悬念或反直觉？
- [ ] 每个观点是否有具体案例支撑？
- [ ] 读起来像不像真人在说话？
- [ ] 是否有明确的"读者看完能做什么"？

## 典型结构

```
标题：反直觉观点 + 数字

开头（Hook）：一个让人意外的故事或数据

"你可能会觉得……但实际上……"

第一部分：为什么这个问题重要
第二部分：常见的错误认知
第三部分：新的解决框架
第四部分：具体怎么做

结尾：一句金句 + "从今天开始，你可以……"
```

## 失败模式

- 如果话题过于宽泛，先缩小到 1 个具体场景
- 如果没有真实数据，诚实说"据我观察"，不要编造
- 如果文章超过 4000 字，检查是否有重复内容
